# TERE YATIRIM

Hiciv bir borsa oyunu: hisseyi topla, pompala, halka boşalt; SPK radarına ve halkın öfkesine yakalanmadan kaç.

**Oyna:** https://revqqwer.github.io/tere-yatirim/

iPhone'a kurmak için: Safari'de aç → Paylaş → "Ana Ekrana Ekle".

> Bu bir hiciv oyunudur. Şirketler, hisseler ve kişiler kurgudur. Pump and dump ve piyasa dolandırıcılığı gerçek hayatta ağır suçtur; mağdurları gerçek insanlardır.
